# Чиста зведена версія OrionAI

Цей каталог зібрано з кількох архівів без дублювання файлів.

## Основа
- За основу взято `OrionAI-full.zip` / `OrionAI-update.zip` як найновішу й найповнішу гілку коду.
- `OrionAI-update.zip` є підмножиною `OrionAI-full.zip` з ідентичними файлами.
- Із `OrionAI-main.zip` додано `.gitignore`, якого не було в найновішому повному архіві.
- Старі версії `bot.py`, `manager.py`, `backups.py`, `Dockerfile` не дублюються.

## Виправлені конфлікти
- `.env.example`: видалено дублікати `BOT_TZ` і `AUTO_BACKUP_DAYS`.
- `AUTO_BACKUP_DAYS=0`, щоб автокопії не запускалися без явного ввімкнення.
- Прибрано посилання на відсутні `docs/01-whatsapp.md` і `docs/01-instagram.md`.
- README більше не посилається на `simulation/`, бо ця папка була лише для попереднього перегляду й свідомо не включена.
- `__pycache__` і `.pyc` не включені.

## Обрані новіші версії
- `bot.py` — версія з акордеонним меню, режимами роботи, webhook/serverless та кластерною логікою.
- `manager.py` — версія з планами сну/пробудження, схемами моніторингу й кластером.
- `backups.py` — ZIP/TAR.GZ/DB.GZ, повна/дані, автокопії вимкнені за замовчуванням.
- `Dockerfile` — без `VOLUME` (сумісно з Railway), з `/data` та копіюванням проєкту.

Цей архів призначений для завантаження в новий приватний GitHub-репозиторій.
