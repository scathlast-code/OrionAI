# 🚂 Railway: як тримати OrionAI, щоб нічого не губилося

## 1. Диск для даних (обов'язково)
Railway стирає файли контейнера при **кожному** оновленні коду чи перезапуску. База бота (розмови, теки, завдання, налаштування, доступи) лежить у `/data/bot.db`, тож без диска вона щоразу зникатиме.

1. Railway → ваш проєкт (полотно з сервісом **OrionAI**).
2. **+ Create** (на комп'ютері також правий клік по полотну або ⌘K) → **Volume** → оберіть сервіс **OrionAI**.
3. **Mount path:** `/data` — саме так, без лапок.
4. Railway перезапустить сервіс — дочекайтесь статусу Active.

Як перевірити: бот більше не пише «⚠️ Дані бота лежать у /data, але там не підключено Railway Volume…», а в «⚙️ Налаштування → 🩺 Стан бота» немає цього рядка.

> Рядок `VOLUME ["/data"]` у Dockerfile Railway не приймає — тому його прибрали. Але сам по собі цей рядок диска не створює: диск підключається лише в налаштуваннях Railway, як описано вище.

## 2. Змінні (Variables)
Обов'язкові:
- `TELEGRAM_TOKEN` — токен від @BotFather;
- `ALLOWED_USERS` — ваш Telegram ID (бот покаже його, якщо написати йому без доступу);
- `MCP_SECRET` — довгий випадковий рядок (від 16 символів).

Моделі ШІ — хоча б один ключ: `GEMINI_API_KEY`, `GROQ_API_KEY`, `MISTRAL_API_KEY`… (як отримати — `docs/02-modeli.md`).

Не потрібні, якщо головного бота окремо не запускаєте: `MANAGER_TOKEN`, `MANAGER_SECRET`, `HUB_URL`, `HUB_KEY`.

Не додавайте «Suggested Variables» з прикладами-заглушками (`123456:ABC…`, `example.com` тощо) — вони лише заважають.

## 3. Скільки це коштує
- Перші 30 днів — пробний період з одноразовими $5.
- Потім безкоштовний план дає лише **$1 на місяць** і 0,5 ГБ пам'яті. Бот, що працює цілодобово, зазвичай витрачає більше — коли кредит закінчиться, Railway його зупинить до наступного місяця.
- Щоб бот працював завжди: тариф **Hobby ($5/міс, у ці $5 входить використання)** або безкоштовний сервер Oracle Cloud (`docs/03-server.md`).
- Диск (Volume) на безкоштовному плані — до 0,5 ГБ; базі бота цього вистачає надовго.

## 3а. Як не спалити $1 раніше строку — режими роботи
У боті: **⚙️ Налаштування → ⚡ Режим роботи**.
- 🟢 **Завжди активний** — бот постійно слухає Telegram, усе вчасно; Railway рахує кожну хвилину. Serverless у Railway — вимкнути.
- 😴 **Сон між розмовами** — Telegram сам надсилає боту повідомлення (вебхук), тому Railway може приспати сервіс після 10 хв тиші; сплячий сервіс не коштує нічого. Перша відповідь після сну — на кілька секунд довша. Завдання за розкладом чекають, доки ви напишете.
- ⏰ **Сон + будильник** — як «Сон», але бот ще прокидається в задані години й до кожного запланованого завдання, виконує все і знову засинає.

Для режимів сну:
1. Railway → сервіс → **Settings → Networking → Generate Domain** (порт — той, що пропонує Railway).
2. **Settings → Deploy → Serverless** → увімкнути.
3. У боті обрати режим. (Змінна `TG_WEBHOOK=1` лише задає режим «Сон» за замовчуванням для нового сервера.)

Будильник (для ⏰):
- **Автоматично:** зареєструйтесь на cron-job.org (безкоштовно) → Settings → API → створіть ключ → Railway Variables → `CRONJOB_API_KEY`. Бот сам ставить і прибирає пробудження, зокрема до кожного завдання.
- **Вручну:** у боті «⏰ Будильник» показує адресу пробудження — створіть на cron-job.org завдання з цією адресою на потрібні години.

Не підключайте головного бота (HUB_URL/HUB_KEY) у режимах сну: сигнал «я живий» раз на 5 хв не дасть засинати.
Скільки економить: якщо ви спілкуєтесь із ботом годину-дві на день, він працює ~2–3 год на добу замість 24 — $1 вистачає на місяць із запасом.

## 4. Головний бот (🧭 manager.py)
На Railway запускається лише ШІ-бот (`CMD ["python", "bot.py"]`). Головного бота за бажанням — окремим сервісом у тому ж проєкті з командою `python manager.py`, своїм `MANAGER_TOKEN` і **своїм** Volume на `/data` (файл бази в нього інший — `manager.db`).

## 5. Синя кнопка «Меню» Telegram
Бот сам ставить у ній лише `/start` і `/menu` при кожному запуску. Довгий список команд у @BotFather не потрібен — його можна очистити: @BotFather → /mybots → бот → Edit Bot → Edit Commands → надіслати лише
```
start - Запустити бота
menu - Відкрити кнопкове меню
```

## 6. Резервні копії
Автоматично бот **нічого не архівує**, доки ви самі не задасте розклад (⚙️ Налаштування → 💾 Копії → місце → ⏱ Розклад). Перед великими змінами коду зробіть копію вручну: «💾 Зробити копію зараз» — файл ZIP можна зберегти у «Файли» на iPhone.
