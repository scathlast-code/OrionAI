# 🗃 Аудит старих архівів (22.11.2026)

Перевірено всі надіслані архіви (39 ZIP, ~1 250 файлів .py, частина — дублікати): етапи 1–34, REBUILT_COMPLETE_COLLECTION,
FULL_DIALOG_FILES_FOR_CLAUDE (усі проміжні версії bot.py), OrionAI-main/-full/-update/CLEAN_MERGED, MediaBot, sticker_oracle_bot,
ai-bots-telegram, orion_youtube_pot_pack/candidate, GreenPost AI Newsroom, журнали розмов і промтів.

Метод: порівняння назв модулів і всіх функцій (def) зі старих версій із поточним кодом + перевірка кожної вимоги зі старих журналів.

## Висновок
Код зі старих архівів уже в поточному боті: усі 48 модулів етапу 34 на місці; зі старих функцій бракує лише службових
(старий механізм згортання кнопок `_fold_*`, замінений новим, і окремі обгортки MediaBot/Sticker Oracle, чиї можливості
перенесені в модулі «Завантажити» й «Наліпки»).

| Вимога зі старих журналів | Стан у поточному боті |
|---|---|
| Держпосади: призначення/звільнення, регіони України й світу | є (government_positions/regions/coverage) |
| Режими: інкогніто, без інтернету, лише з інтернетом, «сили Оріону» | є (orion_modes) |
| Доступ за країнами й окремими територіями | є (тести security_regions) |
| Ієрархія ботів: підлеглий і керівник, захист від циклів, журнал | є (hierarchy) |
| Зведення 2000/2100/2200 знаків, загиблі/поранені без подвійного обліку | є |
| Файли: до 10 вкладень, архіви ZIP/RAR/7z, колажі, конвертація | є |
| Бекапи ZIP/TAR.GZ/DB.GZ, за замовчуванням вимкнені; хмари | є |
| Моніторинг правил і тарифів сервісів, постійні тривоги | є |
| Конструктор кнопок і сценаріїв поведінки | є |
| UTM: реєстр 3 дні, резервні формати, ✅, Word/Excel, скорочення й кліки | є |
| Меню-акордеон ▼/▲, «Назад / Додому / Вперед» | є |
| Стікери й емодзі: архіви, GIF, об'єднання | є |
| MediaBot: нарізка, субтитри, звукова доріжка, очищення метаданих | є (модуль «Завантажити») |
