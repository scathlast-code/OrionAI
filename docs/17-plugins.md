# 🔌 Плагіни Оріона: 📰 Ньюзрум і 🧷 Стікери

Нова головна категорія меню **🔌 Плагіни** (☰ Меню → 🔌 Плагіни ▼) — одразу після «💬 Робота».
Усередині: **📰 Ньюзрум**, **🧷 Стікери** і **🔌 Усі плагіни** (стан, увімкнення/вимкнення, довідка).
Як і будь-які розділи, ці кнопки можна перенести, перейменувати чи сховати в «🧭 Меню й кнопки».
У старих користувачів категорія додається автоматично (міграція `plugins_menu_v5`), власні налаштування меню не чіпаються.

## Як влаштовано

```
plugins/
  __init__.py          реєстр, Host (що бот дає плагінам), меню «🔌 Плагіни», увімкнення/вимкнення
  newsroom/            📰 Ньюзрум GreenPost
    __init__.py        екрани, кнопки, прийом, воркер черги, публікація, вебхуки
    engine.py          правила редакції, рерайт, точна довжина, зведення, звірка
    store.py           SQLite: матеріали, чернетки, версії, джерела, налаштування
    feeds.py           безпечне читання RSS/Atom
  stickers/            🧷 Стікери
    __init__.py        екрани, історія, стеження, перехоплення стікерів і посилань
    exporter.py        експорт пакетів: частини ZIP, без повторів, PNG, прогрес
```

- Плагіни **не імпортують bot.py** — усе потрібне передається через `Host` (моделі ШІ, браузер, вебпошук, запит тексту, Telegram-бот).
- Помилка в одному плагіні не валить бота: реєстр ловить винятки й показує їх у «🔌 Усі плагіни».
- Вимкнений плагін зникає з меню, не перехоплює повідомлення, не запускає фонових перевірок; дані лишаються.
- Дані — `data/plugins/news/newsroom.db`, `data/plugins/stk/stickers.db`. Обидві бази тепер додаються в резервні копії ZIP і tar.gz (`data/plugins/…`). Автовідновлення з меню повертає основну базу; бази плагінів — покласти на місце вручну.

## 📰 Ньюзрум

Перенесено з GreenPost AI Newsroom v1.0 (Telegram + WhatsApp + n8n + OpenAI). Вихідного коду v1.0 в архіві не було — лише README й діалог, — тому плагін написано заново за тим README, але **на моделях Оріона** замість окремого платного OpenAI API: працює «🔁 Авто» з перемиканням між безкоштовними Gemini / Groq / Mistral / …, з тією самою чергою пріоритетів.

Доступ — лише власникам бота (ALLOWED_USERS).

### 📋 Списки каналів і чатів (головне джерело)

📰 Ньюзрум → **📋 Списки джерел**. Бот сам, за розкладом, перевіряє кожне увімкнене джерело з ваших списків і бере нові дописи.

**Завантажити**: «📤 Завантажити файл» → надіслати .txt / .csv / .xlsx / .json (до 5 МБ) або вставити текст.
```
## Області
@kyiv_oda | КМВА | Київ
https://t.me/lviv_oda | Львівська ОВА | Львівська
t.me/+Запрошення | Закритий чат волонтерів
-1001234567890 | Група громади | | ні
## Екологія
@greenpostua | GreenPost
```
`## Назва` — новий список; поля після посилання (назва, область, так/ні) необов'язкові; у CSV/Excel можна заголовки «посилання, назва, область, увімк»; кожен аркуш Excel — окремий список. Нерозпізнані рядки показуються з номерами.

**Редагувати** (усе кнопками):
- список: перейменувати, увімкнути/вимкнути, інтервал перевірки (5 хв – 3 год), фільтри «лише зі словами» / «без слів», мінімальна довжина допису, область за замовчуванням, вище/нижче, об'єднати з іншим, вивантажити CSV, видалити;
- джерело: увімкнути/вимкнути, ⏫ ⬆️ ⬇️ ⏬, «🔢 На позицію», назва, область, спосіб читання, перенести в інший список, перевірити зараз, видалити;
- 🔃 сортування: А–Я / Я–А, за областю, найактивніші, свіжі дописи, нові в списку, проблемні вгорі, вимкнені вниз, перевернути;
- ✂️ масові дії: видалити / вимкнути / увімкнути за номерами (`3, 5-8, 12`), усі вкл/викл, прибрати з помилками, вимкнені, ті, що вже є у вищих списках, **замінити весь список файлом**;
- 📥 вивантажити все в CSV (Excel відкриває з кирилицею) і TXT — відредагуйте й завантажте назад.

**Хто що читає**
| Джерело | Як читається | Що потрібно |
|---|---|---|
| Публічний канал | 🌐 вебпревʼю t.me/s/… | нічого |
| Канал/група, на які підписаний службовий акаунт | 📲 у реальному часі | TELEGRAM_SESSION |
| Публічний канал без підписки, група за посиланням, приватний канал за запрошенням (акаунт уже учасник), чат за id | 📲 опитування | TELEGRAM_SESSION |
| Канал, де бот адмін; група, куди доданий бот | 🤖 дописи приходять самі | для груп — вимкнути Privacy Mode у @BotFather (`/setprivacy` → Disable), інакше бот бачить лише команди |

Перша перевірка джерела лише запам'ятовує наявні дописи, щоб не залити чергу старими новинами. Один і той самий допис, що є в кількох списках, береться один раз. Відсіяне фільтром не йде в ШІ й рахується в «відсіяно».

### 📲 Канали, чати й групи, на які підписаний акаунт

Бот у Telegram не може сам підписуватися на канали, тому підписки читає **службовий акаунт** (звичайний акаунт Telegram, краще окремий, із 2FA) через MTProto (Telethon):
1. https://my.telegram.org → API development tools → `api_id`, `api_hash`.
2. На сервері: `docker compose run --rm -it ai python -m plugins.newsroom.make_session` — увійти кодом.
3. У `.env`: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION` → `docker compose up -d ai`.

Після цього всі канали й групи акаунта стають списком **«📲 Підписки акаунта»** і читаються в реальному часі. Підписались з телефону на новий канал — він з'являється сам (одразу увімкнений або вимкнений — перемикач «Нові підписки»). Відписались — джерело позначається «акаунт більше не підписаний». Синхронізація — раз на 6 год і кнопкою. Особисті листування не читаються, якщо не задати `NEWSROOM_READ_PRIVATE=1`. Рядок сесії = повний доступ до акаунта: тільки в `.env` на сервері.

Групи, куди доданий сам бот, і канали, де він адмін, потрапляють у список **«🤖 Де є бот»** — бот питає, чи моніторити.

**Захист лімітів**: не більше `hour_cap` (60) матеріалів на годину йде в ШІ, решта чекає в черзі й не губиться; для груп у «🤖 Де є бот» мінімальна довжина допису — 60 символів.

### 🔎 Знайти й написати (пульт)
Кнопки 🔥 Гарячі · ♾ Вічні · 🌶 Провокації · ✍️ Блоги й теми (🌾 Агро, ⚡️ Енергетика, 🩺 Здоровʼя, 🌿 Екологія — список тем редагується) → розмір 📱 Коротко / 📰 Новина / 📚 Велика. Бот:
1. шукає свіже в інтернеті (Google News RSS з часом і джерелом; запасний шлях — вебпошук Оріона);
2. відсіює заблоковане й спам;
3. оцінює кожен матеріал моделлю: важливість, відповідність тематиці медіа, терміновість, достовірність джерела (офіційне / медіа / блог / анонім), рекламність; рахує пріоритет;
4. групує схоже в **історії** й звіряє з **нашими ресурсами**;
5. пише одну органічну публікацію з кількох матеріалів (**біг ньюз**) за шаблоном, з посиланнями, атрибуцією, переліком непідтвердженого й оцінкою достовірності в примітках;
6. надсилає список знайденого (кожне з кнопкою ⋯) і готову чернетку. Велика стаття за ввімкненого сценарію одразу йде у **Word українською й російською**.

«♾ Вічні» й «🌶 Провокації» спершу просять модель запропонувати кути (провокації — лише на реальних фактах, без образ і маніпуляцій), потім шукають підтвердження.

**Дії біля кожної знахідки (⋯)**: 📱 Коротко · 📰 Новина · 📚 Багато · ✅ Підтвердити (звірка пошуком) · ❌ Спростувати (лише за підтвердженими доказами) · ✏️ Нотатка · 📁 Перемістити (⭐ Обране / ⏳ Пізніше / 🗄 Архів) · 🔗 Схожі (історія) · 🚫 Блокувати (джерело, сайт, тему, людину) · 🗑 Видалити · 🌐 Відкрити.

### 📣 Відгомін наших новин
🏠 Наші ресурси → 📣 Відгомін: усе, що бот збирає (списки, підписки акаунта, канали з ботом, RSS), звіряється з нашими публікаціями:
| Вид | Як визначається |
|---|---|
| 🔁 Репост / пересилання | переслано з нашого каналу (Telegram показує джерело) |
| 📄 Передрук із посиланням | майже дослівно (≥ 85 %), але з посиланням / назвою |
| 🚩 Плагіат | майже дослівно (≥ 85 % однакових фрагментів, близька довжина) **без** посилання |
| 💬 Цитування | є дослівний відрізок від 12 слів |
| ✍️ Переказ | та сама новина своїми словами (з посиланням чи без) |
| 🏷 Згадка | назва, @канал чи домен без спільного тексту |

**Рерайт ніколи не вважається плагіатом** — лише ідентичний або майже ідентичний текст. Визначення детерміноване (без ШІ), щоб модель не «вгадувала». Репости, передруки й плагіат нашого тексту не потрапляють у чернетки. Сповіщення: 🔔 Важливе (плагіат, репост, передрук, цитата) / 🔔 Усе / 🔕 Тихо. «🏷 Наші назви» — як нас називають і де посилаються (назви, @канали, домени).

### 🏷 Теги (лише стежити)
Тег шукає за запитом (OR, "фраза", -мінус) за розкладом (30 хв – доба) і надсилає дайджест: заголовок, джерело, час, короткий опис, посилання, сортування ⭐ / ⏱ / 📡. Нічого не пише сам — писати з картки знахідки або «📚 Біг ньюз із верхніх».

### 🏠 Наші ресурси
Канали, чати й сайти (RSS) редакції. Звідти новини **не беруться**: бот запам'ятовує наші публікації (і все, що опублікував сам ньюзрум) і кожну нову новину звіряє з ними: ♻️ повтор (не береться), ➕ доповнення, 🔁 оновлення, ❌ спростування. Тоді бот надсилає повідомлення з **усіма нашими згадками** й **усіма попередніми оновленнями** цієї історії плюс кнопки «🔁 Написати оновлення» / «❌ Написати спростування».

### 🌐 Соцмережі (📡 Джерела → 🌐 Соцмережі)
X (Twitter), Threads, Instagram, Facebook, Tumblr, YouTube і будь-який RSS додаються **так само, як канали** — посиланням у будь-який 📋 список (чужі — джерела новин) або в 🏠 Наші ресурси (наші — не беремо, лише звіряємо, рахуємо охоплення й відгомін). Короткий запис теж працює: `x:name`, `threads:name`, `ig:name`, `fb:page`, `tumblr:name`, `yt:<id каналу>`, `rss:https://…`. Усі фільтри, блокування, антиспам, 📣 відгомін і 📅 теми дня діють однаково.

| Мережа | Без ключів | З ключем у .env |
|---|---|---|
| 𝕏 X | лише через власний RSSHub | `X_BEARER_TOKEN`: будь-які публічні акаунти + перегляди, лайки, репости, відповіді |
| 🧵 Threads | RSSHub | `THREADS_TOKEN`, `THREADS_USERNAME`: ваш акаунт + перегляди й реакції |
| 📸 Instagram | RSSHub | `META_TOKEN` + `IG_USER_ID`: ваш і чужі Business/Creator-акаунти (лайки, коментарі) |
| 📘 Facebook | RSSHub | `FB_PAGE_TOKENS=сторінка=токен,…`: ваші сторінки (реакції, коментарі, поширення); чужі — з дозволом Page Public Content Access |
| 🌀 Tumblr | RSS | `TUMBLR_API_KEY`: ще й кількість нотаток |
| ▶️ YouTube, 🌐 RSS | RSS | — |

`RSSHUB_URL` (+ `RSSHUB_KEY`) — ваш власний RSSHub, запасний шлях для чужих акаунтів без офіційного доступу; він читає публічні сторінки, працює не завжди, правила платформ — на власнику. Частота: X — раз на 30 хв, Instagram — 20 хв, Facebook і Threads — 15 хв на акаунт. Ключі — лише в .env, у журнали не пишуться.

Telegram: канали, групи, чати й гілки коментарів (через 📲 службовий акаунт), бот у групах, вебпревʼю t.me/s; для наших каналів бот щоразу оновлює перегляди, реакції, пересилання й коментарі.

- 📣 відгомін на чужих ресурсах: цитування, репости, перекази, передруки, 🚩 плагіат (лише майже дослівно без посилання — рерайт ніколи не плагіат), хто нас найчастіше підхоплює;
- ⏰ день тижня й час, коли заходить краще; 🏆 найсильніші дописи (у файлі); порівняння з попереднім місяцем.

📌 **Закріпити рідкісне**: позначте пункти (теми й області, де просідаємо) — «📌 У головному меню» показує їх рядком над меню Оріона й ньюзруму (лише адміністраторам) з кнопкою «📌 Де просідаємо — звіт»; «📍 Повідомленням у чаті» — закріплене повідомлення вгорі чату, яке бот сам оновлює щомісяця (🔁 / ⏸). «🧹 Відкріпити» — прибрати.

| Підписки службового акаунта | 📲, див. вище |

| RSS / Atom | 📡 Джерела → ➕ Додати RSS. Перше читання лише запам'ятовує наявні пости |

Посилання без тексту бот відкриває сам (той самий браузер, що й `/browse`) і пише новину зі сторінки.
Фото читається моделлю з підтримкою зображень.

### Обробка
1. **Дублікати** за 72 години: точний збіг або ≥ 60 % однакових 4-слівних фрагментів — не обробляються («♻️ повтор #…», кнопка «Все одно обробити»). 30–60 % — матеріал позначається як можливе **оновлення події**, і попередня версія передається моделі.
2. **Рерайт** за правилами GreenPost: українська, без вигаданих фактів, підтверджене окремо від непідтвердженого, атрибуція, області (Київ першим), без подвійного підрахунку загиблих/поранених, без даних, що шкодять безпеці. Свої правила — ⚙️ → 📜 Правила редакції.
3. **Точна довжина**: якщо задано (напр. 2000), бот сам рахує символи й до 5 разів просить модель підігнати. Не вийшло — статус «📏 Не та довжина», кнопка «Схвалити» не спрацює.
4. Нереклама/не новина — пропускається з поясненням.
5. Помилки моделі — 3 спроби з паузою; далі «⚠️» у «⏳ Черга» з кнопкою «🔁 Ще раз». Черга переживає перезапуск.

### Чернетка
`✅ Схвалити · 🔁 Переписати · ✍️ Правка (своїми словами) · 📏 Довжина · 🔎 Звірити · ❌ Відхилити · 📄 Оригінал · 🕘 Версії · 📋 Чистий текст`
- **🔎 Звірити** — вебпошук Оріона (Tavily/Brave/…/DuckDuckGo/GDELT) + модель: по кожному твердженню ✅/⚠️/❌. Це допомога, а не фактчек.
- **🕘 Версії** — до 10 попередніх, будь-яку можна повернути.
- **📤 Опублікувати** — лише схвалене й лише в підключений канал (⚙️ → 📤 Підключити канал: додати бота адміном і переслати допис). «🚀 Одразу» публікує в момент схвалення — але все одно лише після вашої кнопки.

### 🧾 Зведення: збір → сценарій → стаття
1. **Збір**: 🔎 Знайти й написати → 🧾 Зведення → «▶️ Почати збір» (або `/collect`). Усе, що надсилаєте — тексти, переслані дописи, посилання, фото з підписами, txt-файли — складається без обробки й без ШІ; бот відповідає лише «✅ Прийнято · N». Зібране зберігається в базі й переживає перезапуск. «📋 Що зібрано» — перелік, «🗑 Прибрати останнє», «🗑 Очистити зібране», «➕ Новини ньюзруму за добу на тему…» — додати готові матеріали лише на обрану тему (⚔️ Війна, ✨ Астрологія, 🐾 Права тварин, 🌿 Екологія, 🌾 Агро, ⚡️ Енергетика, 🩺 Здоровʼя або всі; теми й ключові слова редагуються в ✍️ Як писати → 🗂 Теми пошуку).
2. **Шаблон**: кнопки «Готуй: …» — ваші шаблони (⚙️ Шаблони зведень): назва, обсяг (напр. рівно 2000, бот перевіряє сам), ідеї й вказівки, адресат (👀 мені на перегляд / 📤 одразу в канал / 🤖 конкретному дочірньому боту), «🧹 очищати після». Типові: «🧾 Зведення 2200», «🧾 Зведення 2000», «🧾 Зведення 1000» (рівно стільки знаків разом із пробілами; бот рахує сам і до 5 разів підганяє).
3. **Сценарій**: перед роботою бот пропонує обрати внутрішній сценарій-промт — 📍 За областями, 🔥 Головне зверху, ⏱ Хронологія, 📊 Цифри й факти, 🗣 Для соцмереж, 🧾 Сухий звіт, ✍️ свій промт або ▶️ без сценарію. Сценарії редагуються: «🎭 Сценарії» (`Назва | промт`).
4. **Результат**: одна стаття з усього зібраного + файл «Зібрані матеріали». На перегляд — картка з вашими кнопками (📤 🤖 🗄 📁 📋 🗑). Дочірньому боту — стаття й усі матеріали (кількома подіями, щоб нічого не обрізалось); його відповідь — у «📥 Вхідні».
Колишнє «зведення за добу» лишилось: `/digest 2000` (2100, 2200…).

## 🧷 Стікери

Об'єднано Sticker Oracle Bot (окремий бот на Oracle Cloud) і `/stickers` Оріона.
Окремий сервер Oracle для стікерів більше не потрібен — усе працює в Оріоні.

- Посилання `t.me/addstickers/…`, `t.me/addemoji/…` (до 30 за раз): «📥 Завантажити пакети», `/stickerpack …` — або просто надішліть повідомлення з посиланнями чи **сам стікер**: бот запропонує кнопки.
- **📦 Один архів** — теки за пакетами, однакові файли між пакетами — один раз (як `/merge` в Oracle-боті). **🗂 Окремо** — свій ZIP на пакет.
- Архів понад 45 МБ ділиться на самостійні частини (обмеження Bot API на відправлення ~50 МБ).
- Паралельне завантаження (6 файлів), прогрес-бар в одному повідомленні, звіт із помилками по кожному пакету, `manifest.json` у кожній теці.
- **🖼 PNG** — копії статичних .webp у PNG (Pillow).
- **🔎 Про пакет** — назва, тип, кількість статичних/анімованих/відео без завантаження.
- **🕘 Історія** — останні 10 завантажень із «🔁 Повторити».
- **👁 Стеження** — раз на 6 год перевіряє пакети й пише «оновився: +3 / −1» з кнопкою завантаження.
- **🧩 Вибрати окремі** — чернетка з кнопками вибору й затвердження (наявний механізм `sticker_drafts`).

Змінні (необов'язкові): `STICKER_MAX_PACKS=30`, `STICKER_PART_MB=45`, `STICKER_MAX_FILE_MB=19`, `STICKER_TOTAL_MB=400`, `STICKER_PARALLEL=6`.
