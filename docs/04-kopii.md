# Резервні копії

Копія — це вся база бота: розмови й теки, завдання, нотатки, закріплене, архів, кошик, медіатека, налаштування й кнопки. У головного бота — список ботів, правила й події. Ключі й токени з `.env` у копію не входять: зберігайте файл `.env` окремо (наприклад, у менеджері паролів). А от підключення хмар, Canva й сервісів (`🔗 Сервіси`) входять, щоб після відновлення нічого не довелося підключати заново. Тому обов'язково задайте пароль копій (нижче).

Керування: **🧰 Інструменти → 💾 Резервні копії** (окремо в ШІ-боті й у головному боті).

## Куди можна зберігати

| Куди | Безкоштовно | Що налаштувати |
|---|---|---|
| 📱 **Файлом у чат** | завжди | нічого: копія приходить вам файлом, який можна зберегти на телефон («Зберегти у Файли») |
| 📢 **Приватний канал Telegram** | без обмежень | канал + бот адміністратором |
| 🟢 **Google Диск** | 15 ГБ | застосунок у Google Cloud (10 хв, один раз) |
| 🔵 **Dropbox** | 2 ГБ | застосунок у Dropbox (5 хв) |
| 🟦 **OneDrive** | 5 ГБ | застосунок у Microsoft Azure (10 хв) |

Можна кілька місць одночасно. **Автоматичні копії за замовчуванням вимкнені**: бот нічого не архівує сам, доки ви явно не задасте розклад. У кожного місця свій розклад: місце → «⏱ Розклад копій»:
- щодня, раз на 3 дні, раз на тиждень, раз на місяць;
- щодня о певній годині або раз на тиждень у певний день і годину;
- «⏸ Пауза на тиждень» або «⏹ Зупинити»;
- ручна копія працює незалежно від автокопій.

### Формати і вміст

У «📦 Формати» можна вибрати один або кілька форматів одночасно:
- **ZIP** — найзручніший для iPhone і ручного перегляду;
- **TAR.GZ** — універсальний серверний архів;
- **DB.GZ** — компактна технічна копія SQLite-бази.

У «🗂 Вміст копії»:
- **Лише дані** — база бота;
- **Повна копія OrionAI** — база + доступні на сервері файли коду/документації. `.env`, токени та API-ключі не включаються. Код із повної копії відновлюється вручну через GitHub; кнопка «Відновити» в боті автоматично відновлює базу даних.

Вручну копію можна зробити будь-коли: «💾 Зробити копію зараз» або «☁️ Копію зараз» у конкретному місці. Якщо вибрано кілька форматів, бот створить окремий файл кожного формату. У кожній хмарі бот тримає 10 останніх файлів (`BACKUP_KEEP`), а старіші видаляє сам.

**Пароль.** Задайте `BACKUP_PASSWORD=` у `.env`, і всі копії будуть зашифровані (AES-256). Без пароля їх ніхто не прочитає, навіть якщо хмару зламають. **Запишіть пароль окремо**: без нього копію не відновити.

## Приватний канал Telegram

1. Telegram → новий **канал** → тип **Приватний**, назва, наприклад «Копії ботів».
2. Канал → Адміністратори → додайте свого бота з правом **Публікувати повідомлення**.
3. У боті: Резервні копії → «📢 Приватний канал Telegram» → перешліть боту будь-який допис із цього каналу.

> Telegram дозволяє ботам завантажувати назад файли до 20 МБ. Цього вистачає на роки розмов, бо копія стиснута. Якщо копія колись стане більшою, відновлюйте її з Google Диска / Dropbox / OneDrive або файлом.

## Google Диск

1. **console.cloud.google.com** → угорі «Select a project» → **New project** → назва «Мої боти» → Create.
2. **APIs & Services → Library** → знайдіть **Google Drive API** → **Enable**.
3. **APIs & Services → OAuth consent screen** (або **Google Auth Platform**):
   - User type **External**, назва застосунку «Мої боти», ваша пошта.
   - **Data access / Scopes**: додайте `.../auth/drive.file` (доступ лише до файлів, які створив бот).
   - **Audience → Publish app** → **In production**. Для `drive.file` перевірка Google не потрібна. Важливо: у режимі «Testing» Google відкликає доступ через 7 днів.
4. **Credentials → Create credentials → OAuth client ID → Web application**.
   **Authorized redirect URIs** — обидві адреси:
   - `https://ВАШ-ДОМЕН/ai/backup/gdrive/callback`
   - `https://ВАШ-ДОМЕН/hub/backup/gdrive/callback`
5. Скопіюйте **Client ID** і **Client secret** у `.env`: `GDRIVE_CLIENT_ID=`, `GDRIVE_CLIENT_SECRET=` → `docker compose up -d`.
6. У боті: Резервні копії → «🟢 Google Диск» → «Увійти» → оберіть акаунт → «Дозволити». Якщо Google попередить «застосунок не перевірено», натисніть «Додатково → Перейти»: це ваш власний застосунок.

Копії лежать на Диску в теці «Резервні копії bot» / «Резервні копії manager». Бот бачить лише цю теку, а не решту вашого Диска.

## Dropbox

1. **dropbox.com/developers/apps** → **Create app** → **Scoped access** → **App folder** → назва, наприклад `my-bots-backup`.
2. Вкладка **Permissions**: увімкніть `files.content.write`, `files.content.read`, `files.metadata.read` → **Submit**.
3. Вкладка **Settings → OAuth 2 → Redirect URIs** — додайте обидві:
   `https://ВАШ-ДОМЕН/ai/backup/dropbox/callback` і `https://ВАШ-ДОМЕН/hub/backup/dropbox/callback`.
4. **App key** і **App secret** → `.env`: `DROPBOX_APP_KEY=`, `DROPBOX_APP_SECRET=` → `docker compose up -d`.
5. У боті: «🔵 Dropbox» → «Увійти».

Копії — у Dropbox: Програми → `my-bots-backup`.

## OneDrive

1. **portal.azure.com** (вхід звичайним акаунтом Microsoft, безкоштовно) → **Microsoft Entra ID → App registrations → New registration**.
2. Назва «Мої боти». **Supported account types:** «Accounts in any organizational directory and personal Microsoft accounts».
3. **Redirect URI:** платформа **Web**, `https://ВАШ-ДОМЕН/ai/backup/onedrive/callback` → Register.
   Потім **Authentication → Add URI**: `https://ВАШ-ДОМЕН/hub/backup/onedrive/callback`.
4. **Certificates & secrets → New client secret** → термін 24 місяці → скопіюйте **Value** (показується один раз).
   Через 24 місяці створіть новий секрет і замініть у `.env`. Бот нагадає: копія не вдасться і він напише чому.
5. **API permissions → Add → Microsoft Graph → Delegated**: `Files.ReadWrite.AppFolder`, `offline_access`, `User.Read`.
6. **Application (client) ID** зі сторінки Overview і секрет → `.env`: `ONEDRIVE_CLIENT_ID=`, `ONEDRIVE_CLIENT_SECRET=` → `docker compose up -d`.
7. У боті: «🟦 OneDrive» → «Увійти».

Копії — в OneDrive: Програми → «Мої боти».

## Відновлення

**На тому ж сервері:** Резервні копії → «♻️ Відновити з копії». Це меню відновлення: там усі підключені хмари («🟢 Google Диск: обрати копію» тощо) і канал. Оберіть місце, потім копію зі списку (від нових до старих). Бот покаже, що в ній (розмов, нотаток, завдань), і попросить підтвердити. Поточну базу він спершу збереже поруч (`*.pre-restore-…`), тож відновлення можна скасувати.

**З файлу:** просто надішліть боту файл копії (`.zip`, `.tar.gz`, `.db.gz` або зашифрований `.enc`) з телефона → «Так, відновити». Якщо це повна копія, бот автоматично відновить дані з бази всередині архіву; файли коду не перезаписуються автоматично.

**На новому сервері** (старий зламався, Oracle забрав сервер тощо):

1. Підніміть сервер за `03-server.md` з тим самим `.env` (той самий `BACKUP_PASSWORD`, `MANAGER_SECRET`).
2. Напишіть ботові `/start`.
3. Надішліть файл копії або підключіть хмару й відновіть звідти.

Усе повернеться як було, разом із кнопками, теками й завданнями.

> `MANAGER_SECRET` шифрує токени ботів у базі головного бота. Якщо відновити копію з іншим `MANAGER_SECRET`, список ботів повернеться, але токени доведеться ввести знову (картка бота → «🔑 Замінити токен»).
