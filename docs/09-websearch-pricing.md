# Вебпошук: тарифи (перевірено 2026-11-05)

Ціни можуть змінюватися. Безкоштовні кредити та пробні квоти — не безлімітний безкоштовний доступ. **Не підключайте платні рахунки з автоматичним поповненням**, якщо потрібна гарантія нульових витрат. Поточний код не перевіряє баланс провайдера й не встановлює ліміти на його боці.

**Особливість коду:** джерела перебираються по черзі до першого успішного результату, а не об'єднуються. Наявність ключа активує провайдера; код не може гарантувати, що запит не тарифікуватиметься. Для повноцінного браузера потрібні додаткові функції; JavaScript, PDF та авторизовані сторінки тут не підтримуються.
