# 🏘 Групи, канали, спільноти · ⏳ хід роботи

**🏘 Бот у групах, каналах і спільнотах** («🧰 Інструменти → 🏘 Спільноти»)

**Як додати (Telegram)**: група/канал → Додати учасника → бот → зробіть **адміністратором** (видаляти повідомлення, блокувати, запрошувати; у каналі — публікувати). Бот сам з'явиться в списку й напише вам. Типово додавати бота може лише власник — інакше він сам вийде з чату (перемикач 🔒).

**🛡 Правила** — заборони для учасників: посилання, пересилання, фото/файли, стікери й GIF, голосові, згадки @, заборонені слова, КАПС, флуд, тиша для новачків, нічна тиша. Адмінів чату не стосуються.
**⚖️ Покарання**: видалити · видалити й попередити (після N — тиша на добу) · заглушити на час · вигнати.
**👤 Хто що може** — окремі дозволи й заборони понад загальні правила: для **всіх**, для **новачків**, для **групи учасників** або для **конкретної людини**. Кожне правило: ▫️ як загалом → ✅ дозволено → ⛔ заборонено; є «дозволити/заборонити все» й правило «🤐 Писати взагалі» (лише читання).
Де діє: лише в цій спільноті, «🌐 у всіх спільнотах» або «📍 скопіювати в інші» — одну, кілька чи всі.
Пріоритет: людина › група › новачки › усі; налаштування спільноти важливіші за загальні; якщо людина в кількох групах і одна забороняє — забороняє.
**🏷 Групи учасників** («Довірені», «VIP», «Під наглядом»…) — люди з будь-яких спільнот: додати зі списку тих, хто писав, за @ім'ям/ID (кількох одразу), або в чаті у відповідь на повідомлення `/group VIP`, прибрати — `/ungroup VIP`. Кілька @імен в «👤 Учаснику…» — бот сам створить з них групу-вибірку.
**🙋 Дозволи за запитом**: під попередженням є кнопка «Попросити дозвіл» (або команда /request у чаті). Вам приходить запит → ✅ на 1 год / день / 7 днів / назавжди або ❌. Так само — «Попросити розблокувати». Дозволи видно й можна забрати в «🙋 Запити».
**🚪 Вступ**: заявки — приймати всіх, питати вас або не чіпати; привітання новачків ({name} — ім'я); нове посилання-запрошення.
**📣 Публікації**: допис зараз, через годину, у певний час, щодня, щотижня; «🤖 Допис від ШІ» — текст пише модель у момент публікації (лише в ШІ-боті).
**👁 Моніторинг**: слова-тригери або «пересилати все» — вам у приват (і головному боту).
**📜 Журнал** дій і цифри (також у 🩺 Діагностиці).
**📋 Таблиця «де бот»**: скільки груп, каналів і спільнот, з посиланнями, @іменами, кількістю учасників і чи бот адмін; «📄 Файл» — та сама таблиця для Excel/Google Таблиць. Для приватних чатів бот створює власне посилання-запрошення (основне посилання чату не чіпає).

**Команди в групі**: усім — /rules, /request; адмінам чату у відповідь на повідомлення — /warn, /mute 30, /unmute, /ban, /unban, /allow links.

**WhatsApp**: групи вашого номера через Groups API (лише офіційні бізнес-акаунти, до 8 учасників): публікації, заявки на вступ, видалення порушника з групи. Чужі повідомлення WhatsApp видаляти не дозволяє — замість цього попередження (кожне рахується в 1000 безкоштовних/міс).
**Instagram**: груп в API немає; бот модерує коментарі під вашими дописами (сховати/видалити за правилами) і публікує дописи з картинкою.

**⏳ Видно, що бот працює**
Поки ШІ готує відповідь, у чаті висить статус: смужка ▰▰▰▱▱, крок («Крок 2 з 3: 🤖 Groq думає…»), скільки минуло й скільки зазвичай триває (бот запам'ятовує тривалість). Якщо модель не відповіла й бот перемкнувся — там же видно, чому («денний ліміт — пробую Mistral, спроба 2 з 4»). Коли відповідь готова, статус зникає.
**✖️ Зупинити** — перериває роботу; запит лишається в 📒 Журналі, його можна виконати знову.
У WhatsApp та Instagram повідомлення не редагуються, тож там — «друкує…» і одне повідомлення «це займе трохи часу», якщо робота довга.

**Кілька завдань одночасно**
Поки ШІ думає в одній розмові, відкрийте іншу («💬 Розмови → ➕ Нова») і ставте там завдання — хоч іншій моделі. Розмови працюють паралельно, кожна відповідь лягає у свою розмову. В одній розмові запити йдуть по черзі (бот скаже «у черзі»), щоб модель бачила попередню відповідь.

**🔔 Сповіщення про завершення** (коли ви вже в іншій розмові):
✅ готово · ⚠️ треба перемкнутися на іншу ШІ (з варіантами) · ❓ модель просить доповнити запит · 🚫 модель відмовилась — кнопка «🔁 Іншою ШІ» продовжить з того ж місця, вже без тієї моделі.
Кнопка «💬 Перейти в розмову» відкриває потрібну розмову.

## Що потрібно налаштувати

**Telegram**
- Зробіть бота адміністратором групи/каналу: видаляти повідомлення, блокувати користувачів, запрошувати (для заявок); у каналі — публікувати.
- Бот сам отримує події учасників і заявки на вступ (оновлення `chat_member` і `chat_join_request` увімкнені в коді).
- Якщо бот не адмін, Telegram показує йому лише команди й відповіді на його повідомлення (Privacy Mode). Вимкнути: @BotFather → /setprivacy → Disable.
- Заявки на вступ працюють, коли в посиланні-запрошенні ввімкнено «Заявки на вступ». Бот може створити таке посилання сам: 🏘 → чат → 🚪 Вступ → 🔗.

**WhatsApp** (Cloud API Groups)
- Лише номери з офіційним бізнес-статусом (OBA) на Cloud API; до 8 учасників у групі; додати людину напряму не можна — тільки посиланням-запрошенням.
- У кабінеті Meta підпишіть вебхук на поля `group_lifecycle_update`, `group_participants_update` (і `messages`).
- 🏘 Спільноти → «🔄 Мої групи WhatsApp» — бот підтягне групи номера. Заявки бот перевіряє раз на 5 хв.
- Кожне повідомлення бота в групі рахується в ліміт 1000 безкоштовних на місяць.

**Instagram**
- Дозволи застосунку: `instagram_business_manage_comments`, `instagram_business_content_publish`; вебхук — поле `comments`.
- 🏘 Спільноти → «📸 Коментарі Instagram».
- Для допису перший рядок — посилання на картинку (https://…jpg), далі — підпис.

## Безпека акаунта
- Модерація й публікації йдуть лише офіційними API (Bot API, WhatsApp Cloud API, Instagram API) — це дозволені способи, акаунт не блокують.
- Не ставте дописи надто часто й не розсилайте рекламу людям, які не просили, — за спам скаржаться, і тоді Telegram/Meta обмежують бота.
