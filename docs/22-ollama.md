# 🦙 Своя модель на сервері Oracle (Ollama)

Ollama запускає відкриту модель прямо на вашому сервері. Плюси: безкоштовно, без денних лімітів, розмови нікуди не йдуть.
Мінус: на 2 процесорах без відеокарти відповідь пишеться повільно (кілька слів за секунду).

## Увімкнути (один раз)
1. Підключіться до сервера (як у [03-server.md](03-server.md)) і відкрийте `.env` у теці з ботами: `nano .env`.
2. Додайте два рядки:
   ```
   COMPOSE_PROFILES=ollama
   OLLAMA_URL=http://ollama:11434
   ```
3. `docker compose up -d --build`. Тепер поруч із ботами працює сервіс `ollama`. Назовні він не відкритий, до нього ходять лише боти.
4. У ШІ-боті: **🤖 Моделі та ШІ → 🦙 Моя Ollama** → «⬇️ gemma3:4b». Прогрес видно в повідомленні. Перша скачана модель стає робочою.

## Яку модель брати
| Модель | Розмір | Для чого |
|---|---|---|
| `gemma3:4b` | 3,3 ГБ | найкраща з малих: пише українською, бачить фото |
| `qwen2.5:3b` | 1,9 ГБ | швидша, вміє нотатки й нагадування (інструменти) |
| `llama3.2:3b` | 2,0 ГБ | швидка, краще англійською |
| `gemma3:1b` | 0,8 ГБ | найшвидша, найпростіша |

Будь-яку іншу з ollama.com/search можна скачати кнопкою «⬇️ Інша модель». На 12 ГБ пам'яті беріть моделі до 8 млрд параметрів.

## Як користуватися
- `/model моя ollama` — розмова з нею. Разово: `/ask ollama_l питання`.
- В автоматичному порядку вона остання: підхоплює, коли хмарні вичерпали ліміти.
- Відповідь чекає до 5 хв (`OLLAMA_TIMEOUT=300`).

## Пам'ять і Oracle
За замовчуванням модель весь час лежить у пам'яті (`OLLAMA_KEEP_ALIVE=-1`), тож відповідь починається одразу, без 10–40 с завантаження.
`gemma3:4b` займає ~4 ГБ із 12, а процесор працює, поки модель відповідає. Це звичайне навантаження робочого сервісу, і за мірками Oracle сервер
перестає виглядати бездіяльним. Якщо пам'ять потрібна для іншого, задайте `OLLAMA_KEEP_ALIVE=30m`: модель вивантажиться через 30 хв без запитів.

## Вимкнути
Приберіть рядок `COMPOSE_PROFILES=ollama` з `.env` і виконайте `docker compose up -d --remove-orphans`. Скачані моделі лишаються в томі
`ollama-data`; видалити їх назовсім: `docker volume rm orionai_ollama-data` (назва — у `docker volume ls`).
