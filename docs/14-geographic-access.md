# Географічні обмеження OrionAI — Stage 7

Повні країни блокування (ISO 3166-1 alpha-2): RU, IR, CN, KP, US, HU, PL, TR, AF, YE, PS, IL, ID, RS.

**Україна (UA) завжди дозволена географічним фільтром**, зокрема прикордонні райони та тимчасово окуповані території. Інші правила (ідентифікація, rate limit) діють окремо. На практиці IP на окупованій території може геолокуватися як RU через провайдера: система не може безпомилково розпізнати фізичне місце лише за IP. Для таких випадків потрібен безпечний механізм ручної перевірки та винятків за підтвердженим користувачем, який не відкриває доступ усім користувачам RU.

Часткові обмеження: Республіка Сербська (BA), Придністров'я (MD), Абхазія і Південна Осетія (GE). Не блокуємо Боснію і Герцеговину, Молдову або Грузію цілком. Точні коди регіонів мають бути перевірені в **конкретній базі GeoIP City**; налаштовуються змінними `SECURITY_BLOCKED_BA_SUBDIVISIONS`, `SECURITY_BLOCKED_MD_SUBDIVISIONS`, `SECURITY_BLOCKED_GE_SUBDIVISIONS`. Якщо база не повертає точний регіон, система не стверджує, що виконала регіональне блокування.

`SECURITY_GEOIP_DB` повинен посилатися на актуальну базу GeoIP **City**, не лише Country. `SECURITY_WEB_FAIL_CLOSED=1` забороняє невизначені IP, тому для українських користувачів важливо мати актуальну базу та процедуру оскарження хибних блокувань.

Telegram Bot API не надає IP користувача або підтвердженої країни. Отже, геоблокування в чаті Telegram не гарантується. Не використовуйте мову профілю чи номер телефону як доказ фізичного місця. Реальна перевірка IP можлива при вході через Mini App, але VPN та проксі роблять її обхідною. Перевірка по IP не замінює автентифікацію.

Ця збірка не встановлює коди підрегіонів без перевірки даних і не містить бази GeoIP; оператор має налаштувати її та протестувати на власному сервері.
