# OrionAI: браузер, PDF і вартість

- `/browse https://example.org` — читання публічної HTTPS-сторінки. Якщо HTML не містить тексту, використовується Chromium/Playwright для JavaScript.
- PDF: PyMuPDF читає текстові PDF (до 4 МБ, перші 12 сторінок). Скановані PDF без текстового шару потребують окремого OCR.
- Навігація: можна передавати наступні URL командою `/browse`; автономний багатокроковий агент і натискання кнопок ще не реалізовані.
- Авторизація: **не підключена**. Немає автоматичного входу в приватні акаунти, обходу CAPTCHA чи платного доступу. Не надсилайте боту паролі та cookies.
- Playwright і PyMuPDF: відкриті бібліотеки без плати за API. Railway: обчислювальні ресурси й RAM можуть оплачуватися за тарифом хостингу.
- Browserless: сторонній хмарний браузер, необов'язковий, **платні тарифи** після free-плану (1 000 units/місяць, $0; Prototyping $25/міс за річної оплати, за даними сайту на 2026-11-05). Не підключено.
- Пошукові API Tavily, Brave, Serper, SerpAPI, Exa, You.com, SearchAPI: **можуть бути платними**, безкоштовні кредити не означають безумовно безкоштовне використання. Увімкнення ключів і обмеження витрат — відповідальність власника.
- DuckDuckGo HTML: без ключа, неофіційний і ненадійний. Wikipedia/GDELT: публічні API, можуть обмежувати частоту.
- `BROWSER_JS_ENABLED=0` вимикає Chromium; типове значення `1`.
- Безпека: заблоковані очевидні приватні адреси та редиректи. DNS rebinding і поведінка складних вебсайтів потребують додаткового аудиту перед наданням доступу стороннім користувачам.
- Тести: перевірка синтаксису та пакування; реальну роботу Chromium у Railway потрібно перевірити після деплою.
