# 🔗 Таск-менеджери й блокноти

ШІ-бот надсилає ваші завдання й нотатки в хмарні сервіси, показує, що там є, і позначає завдання виконаними.

| Сервіс | Що | Як підключити |
|---|---|---|
| 🔴 **Todoist** | завдання | токен |
| 🟦 **Trello** | завдання (картки) | ключ + токен |
| ⬛️ **Notion** | нотатки й завдання | ключ інтеграції |
| 🟢 **Google Tasks** | завдання | вхід Google |
| 🔷 **Microsoft To Do** | завдання | вхід Microsoft |
| 🟪 **OneNote** | нотатки | вхід Microsoft |
| 📱 **iPhone: Нагадування й Нотатки** | завдання й нотатки, в обидва боки | застосунок «Команди» на iPhone |
| 🐘 **Evernote** | нотатки | поштою (платні тарифи Evernote) |
| ✉️ **Пошта** (TickTick, Things, OmniFocus, Todoist…) | завдання й нотатки | поштою |

**Не підключаються:** Google Keep і ColorNote. Відкритого API для особистих акаунтів у них немає, а неофіційні способи можуть призвести до блокування вашого акаунта Google. Замінники: Google Tasks (той самий акаунт Google), «📱 iPhone», Notion. Для ColorNote — «📋 Копіювати» й вставити.

Розділ у боті: **☰ Меню → 🧰 Інструменти → 🔗 Сервіси**. Сервіси підключаються до акаунтів власника, тож учасники бота їх не бачать.

## Todoist
1. todoist.com → Налаштування → **Інтеграції** → **Розробник** → скопіюйте **API-токен**.
2. У боті: 🔗 Сервіси → Todoist → «🔑 Надіслати токен» → вставте. Повідомлення з токеном бот видалить сам (у WhatsApp/Instagram видаліть його самі).

## Trello
1. **trello.com/power-ups/admin** → **New** → назва «Мої боти», робочий простір → Create.
2. **API key** → **Generate a new API key** → поруч посилання **Token** → **Allow** → скопіюйте токен.
3. У боті: Trello → «🔑 Надіслати токен» → `КЛЮЧ ТОКЕН` через пробіл.
4. «📍 Куди складати» → оберіть дошку й список.

## Notion
1. **notion.so/my-integrations** → **New integration** → тип Internal → скопіюйте ключ (`ntn_…`).
2. У Notion створіть сторінку, наприклад «Нотатки з бота» → **⋯** → **Connections** → додайте свою інтеграцію.
3. У боті: Notion → «🔑 Надіслати токен» → ключ. Кожна нотатка стане окремою сторінкою всередині обраної. Завдання стають сторінками з галочкою.

## Google Tasks
Використовується той самий застосунок Google, що й для копій на Google Диск (`04-kopii.md`):
1. console.cloud.google.com → **APIs & Services → Library** → увімкніть **Google Tasks API**.
2. **OAuth consent screen → Data access** → додайте scope `.../auth/tasks`.
3. **Credentials** → ваш OAuth client → **Authorized redirect URIs** → додайте `https://ВАШ-ДОМЕН/ai/connect/gtasks/callback`.
4. У боті: Google Tasks → «🔐 Увійти».

## Microsoft To Do і OneNote
Використовується той самий застосунок Microsoft, що й для копій в OneDrive:
1. portal.azure.com → ваш застосунок → **API permissions → Add → Microsoft Graph → Delegated**: `Tasks.ReadWrite`, `Notes.ReadWrite`.
2. **Authentication → Add URI**: `https://ВАШ-ДОМЕН/ai/connect/mstodo/callback` і `https://ВАШ-ДОМЕН/ai/connect/onenote/callback`.
3. У боті: Microsoft To Do (або OneNote) → «🔐 Увійти».

## 📱 iPhone: Нагадування й Нотатки

Apple не дає доступу до Нагадувань і Нотаток через інтернет. Тому з ботом їх з'єднує застосунок **«Команди»** (Shortcuts), що вже є на iPhone. Бот складає нові нагадування й нотатки в чергу, а iPhone сам забирає їх за розкладом.

1. У боті: 🔗 Сервіси → 📱 iPhone → «📱 Підключити» → «📋 Адреса» (адреса з ключем скопіюється).
2. iPhone → **Команди** → «+» → назвіть **«Забрати з бота»** і додайте дії:
   1. **Отримати вміст URL** — вставте адресу.
   2. **Отримати значення словника** — ключ `items`.
   3. **Повторити з кожним**, а всередині:
      - **Якщо** «Елемент повторення → kind» **дорівнює** `task`:
        - **Додати нове нагадування** — назва: `title`, примітки: `notes`, дата: `due` (можна обрати список, наприклад «Бот»);
      - **Інакше**:
        - **Створити нотатку** — текст: `title` і `notes`.
3. Вкладка **Автоматизація** → «+» → **Час доби** → наприклад, щогодини з 8:00 до 22:00 (або щоранку) → **Запускати одразу** → команда «Забрати з бота».

**Із iPhone у бот.** Створіть ще одну команду, **«У бот»**, і ввімкніть «Показувати в меню "Поділитися"». Її дія — **Отримати вміст URL**:
- адреса — та сама;
- метод — **POST**;
- тіло запиту — **JSON**, поле `text` = «Вхідні дані команди».

Тепер з будь-якого застосунку: «Поділитися» → «У бот», і текст з'явиться в 📝 Нотатках бота.

## 🐘 Evernote і ✉️ пошта

Evernote не видає нові ключі API, але на платних тарифах приймає нотатки листом на вашу особисту адресу. Так само листом приймають завдання TickTick, Things («Mail to Things»), OmniFocus, Todoist та інші.

1. Пошта, з якої бот надсилатиме листи, — у `.env`:
   `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=587`, `SMTP_USER=ваша@gmail.com`, `SMTP_PASSWORD=` — **пароль застосунку** (myaccount.google.com/apppasswords; потрібна двоетапна перевірка Google).
2. Адреса для листів:
   - Evernote: Налаштування → **Пересилання листів** → адреса `…@m.evernote.com`;
   - TickTick: Налаштування → Додати завдання поштою;
   - Things: Things Cloud → Mail to Things.
3. У боті: 🔗 Сервіси → 🐘 Evernote (або ✉️ Пошта) → «✉️ Надіслати адресу».

## Як користуватися

- **Кнопкою:** у будь-якій нотатці чи завданні бота — «📤 Надіслати в…». Завдання з часом іде в сервіс зі строком.
- **У сервісі:** «📥 Показати» (у завдань є ✅, щоб позначити виконаним) і «➕ Додати». Строк для завдання: `Купити хліб @tomorrow` або `Здати звіт @2026-12-01`.
- **Словами:** «додай у Todoist подзвонити мамі завтра», «що в мене в To Do?», «збережи цю відповідь у Notion». ШІ сам викличе потрібний сервіс.
- **Автоматично:** «Копіювати кожну нову нотатку». Усе, що потрапляє в 📝 Нотатки, з'являється й у блокноті за замовчуванням (⭐️ на сторінці сервісу).

Підключення сервісів зберігаються в базі бота й входять у резервну копію. Тому задайте `BACKUP_PASSWORD`, щоб копія була зашифрована.
