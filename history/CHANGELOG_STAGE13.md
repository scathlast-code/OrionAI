# Stage 13 — сценарії та вебсимуляції

- Реальне збереження незалежних сценаріїв OrionAI/Manager у SQLite.
- Авторизовані API OrionAI Mini App `/api/scenarios`, `/api/scenarios/{slug}`.
- Екран сценаріїв у чинному OrionAI Mini App.
- Команда `/scenarios` материнського Telegram-бота.
- Чотири автономні HTML-симуляції (два боти × Telegram/Mini App).

## Межі
Сценарії зберігають перемикачі, але не всі модулі виконання ще враховують їх. Вебсимуляції офлайн і не пов'язані з сервером. Панель керування доступом у реальному Mini App не реалізована.
